# F-005 — 到期提醒与完成统计

基于任务截止时间和完成事件实现提醒调度及统计查询。具体时间任务默认在结束时间提醒；日期任务默认在截止日当地 09:00 提醒。提醒可关闭，已完成任务不得触发未完成提醒。统计按本地日期和用户选择的时间范围计算任务实例完成率，并生成完成热力图数据。

## Acceptance criteria

- [ ] 启用提醒的有具体时间任务在其结束时间触发默认提醒，日期任务在截止日当地 09:00 触发默认提醒。
- [ ] 关闭提醒或完成任务后，不再产生对应的未完成提醒。
- [ ] 通知权限不足或调度失败时，应用内显示可识别的待处理状态，不丢失任务。
- [ ] 完成率等于指定时间范围内已完成任务实例数除以应完成任务实例数，取消项不计入分母。
- [ ] 热力图按用户本地日期聚合完成实例数，重复任务按实际生成的实例计数。

## Test cases

- [ ] TC-STAT-1: 验证有时间任务和日期任务的默认提醒时刻，并确认关闭提醒后不再调度。 (来源: §4.5-F5)
- [ ] TC-STAT-2: 完成已启用提醒的任务后，断言未完成提醒被取消。 (来源: §4.5-F5)
- [ ] TC-STAT-3: 使用固定时间范围和任务实例集合计算完成率，断言结果符合定义且取消项不计入分母。 (来源: §4.5-F5)
- [ ] TC-STAT-4: 将多个完成实例映射到本地日期，断言热力图每天的计数正确。 (来源: §4.5-F5)
