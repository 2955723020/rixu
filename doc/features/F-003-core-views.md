# F-003 — 今日、未来、逾期、已完成与日历视图

基于任务状态和日期规则实现核心查询层及对应界面数据。提供今日待办、未来任务、逾期任务、已完成和日历五种视图，统一使用用户本地时区进行筛选。逾期任务定义为未完成且当前时刻晚于结束时间；无具体时间的任务在本地截止日结束时刻逾期。逾期任务在列表中红色高亮并按截止时间置顶，完成后立即从逾期集合移除。

## Acceptance criteria

- [ ] 今日视图只返回本地日期等于今天的未完成任务，未来视图只返回今天之后的未完成任务。
- [ ] 已完成视图按完成时间返回已完成任务，恢复未完成后任务从已完成集合移除。
- [ ] 逾期视图只返回超过截止时刻仍未完成的任务；无具体时间任务在截止日结束后才逾期。
- [ ] 逾期任务结果按截止时间升序置顶，并携带红色高亮和非颜色文本/图标语义。
- [ ] 日历视图将任务映射到其截止日期，选择日期可读取该日任务或进入创建流程。
- [ ] 完成、恢复和切换视图不会修改任务原始日期、时间或重复规则。

## Test cases

- [ ] TC-VIEW-1: 在固定本地日期下验证今日和未来筛选边界。 (来源: §4.3-F3)
- [ ] TC-VIEW-2: 构造逾期、未逾期和已完成任务，断言逾期任务置顶且完成后立即移除。 (来源: §4.3-F3；§5-B4)
- [ ] TC-VIEW-3: 验证无具体时间任务在截止日结束前不逾期、结束后逾期。 (来源: §4.3-F3；§5-B7)
- [ ] TC-VIEW-4: 将任务按日期加载到日历视图，选择某日期后只显示该日期任务。 (来源: §4.3-F3)
