# F-004 — 清单、标签、优先级与子任务

扩展 task-lifecycle 的任务组织能力，实现清单分类、多个标签、四级优先级和子任务关系。组织属性均为可选，不得阻塞基础快速创建；删除清单必须明确任务保留、迁移或归档策略。支持按清单、标签和优先级筛选，并保持父子任务状态关系可解释。

## Acceptance criteria

- [ ] 用户可以创建、重命名和删除清单；删除清单时按明确策略保留或迁移其中任务。
- [ ] 任务可以同时拥有多个标签，标签可添加、移除并用于筛选。
- [ ] 优先级至少有四级，可在查询结果中稳定排序和筛选。
- [ ] 任务可以创建和读取子任务关系；父任务在子任务未完成时不会被静默标记为全部完成。
- [ ] 组织属性为空时基础任务仍能在两步以内创建和保存。

## Test cases

- [ ] TC-ORG-1: 创建、重命名并删除清单，验证删除后的任务符合声明的保留策略。 (来源: §4.4-F4)
- [ ] TC-ORG-2: 为任务添加两个标签并按其中一个标签筛选，移除标签后任务不再匹配。 (来源: §4.4-F4)
- [ ] TC-ORG-3: 验证四级优先级的保存、排序和筛选结果稳定。 (来源: §4.4-F4)
- [ ] TC-ORG-4: 创建父任务和未完成子任务，断言父任务不会被静默标记为全部完成。 (来源: §4.4-F4)
