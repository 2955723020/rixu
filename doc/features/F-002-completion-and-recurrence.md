# F-002 — 完成状态与重复任务

基于 task-lifecycle 的任务模型，实现未完成/已完成切换、完成时间记录、正向反馈事件和重复规则。支持每日、每周、每月及自定义间隔规则；完成重复任务时将当前实例标记完成并幂等地生成下一期实例。月度规则保留原始日期锚点，目标月份无对应日期时调整到该月最后一天。

## Acceptance criteria

- [ ] 将未完成任务标记完成会记录完成时间和状态变更事件；重复调用不会改变已记录结果或产生重复实例。
- [ ] 将已完成任务恢复为未完成会清除当前实例 completedAt，并使其重新进入未完成查询。
- [ ] 每日、每周、每月和自定义周期均能根据规则计算下一期实例，并继承任务标题及组织属性。
- [ ] 完成重复任务后当前实例保持已完成，下一期实例为未完成且具有新的截止日期。
- [ ] 月度重复从 31 日跨入无 31 日月份时落到该月最后一天，之后计算仍使用原始日期锚点。
- [ ] 完成操作发布可消费的即时正向反馈，不阻塞状态持久化。

## Test cases

- [ ] TC-REC-1: 完成未完成任务后断言状态为已完成且 completedAt 非空，再次完成不新增实例。 (来源: §4.2-F2；§8-N4)
- [ ] TC-REC-2: 恢复已完成任务后断言状态为未完成且 completedAt 为空。 (来源: §4.2-F2)
- [ ] TC-REC-3: 分别验证每日、每周、每月和自定义规则生成正确的下一期日期。 (来源: §4.2-F2)
- [ ] TC-REC-4: 从 1 月 31 日生成 2 月实例，断言日期为 2 月最后一天；再生成 3 月实例，断言回到 31 日锚点。 (来源: §4.2-F2；§5-B5)
